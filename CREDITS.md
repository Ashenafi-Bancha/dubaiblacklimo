# Image credits

Every photograph on the site is a **placeholder** from [Unsplash](https://unsplash.com), used under the
[Unsplash License](https://unsplash.com/license) (free for commercial use, no permission required).
They are stand-ins for the operator's own photography, in particular the fleet photos, which should be
replaced with pictures of the real vehicles before launch.

The originals are in `client/image-sources/`. To replace one, overwrite the file with your own photo
(keep the file name) and run `pnpm images`.
